# rclona

基于 rclone 的中文网盘备份面板：把一个网盘（源）定时镜像备份到另一个网盘（目标），
失败原因一眼看懂，失败了还会发邮件告诉你。

> 🚧 开发中，部署文档待补全。

## 它能做什么

- **定时镜像备份**：每天几点 / 每周几几点，自动把源网盘同步到目标网盘（纯镜像 + 校验和比对）
- **失败说人话**：每次备份分 5 个阶段，失败时明确告诉你卡在哪一步、是什么原因（密码错了 / 连不上 / 空间不足……）
- **失败邮件通知**：备份失败、网盘连接失效，都会发邮件到你的邮箱
- **网盘连通自检**：每天凌晨自动检查每个网盘还能不能连上
- **多网盘支持**：Cloudflare R2、Koofr、WebDAV、各类 S3、本地目录等（由 rclone 驱动）

## 快速开始（规划中）

```bash
cp .env.example .env   # 按需改端口、账号
docker compose up -d
```

然后打开 `http://你的服务器:8080` 即可。

## 架构

单个 Docker 容器内运行三部分：

| 组件 | 说明 |
| --- | --- |
| 前端 | Vite + React 构建的静态站，网关直接托管 |
| 网关 | Node 服务：登录鉴权、任务调度、运行记录、网盘自检、邮件通知 |
| rclone | 以 `rcd` 模式运行，提供 HTTP rc 接口执行实际同步 |

全部数据（rclone 配置、任务、记录、设置）存放在单一数据卷 `/data`。

## 开发

```bash
cd frontend && npm install && npm run dev   # 前端
cd gateway  && npm install && npm start     # 网关（需本机有 rclone）
```
